REEL DIARY — STAGE 85: APPROVED FILM BOARD

This is a full working app build based on the saved Stage 84 Option 1 compact preview, which in turn is based on the Stage 83 live app.

Changes in Stage 85:
- Keeps the compact 150 x 225 desktop poster and fits the title, genres, status and ratings into the same height as the poster.
- Keeps status above ratings, with the gold vertical accent at the left and a gold tick for Watched. Watchlist keeps the same left accent when that is the film's selected status.
- Keeps rating labels (Your rating and TMDB) in neutral theme text, to the left of their values.
- Restores a bordered Synopsis panel with its heading below the poster/details row.
- Changes the section heading to “Viewing History” and each entry heading to “1st Viewing”, “2nd Viewing”, etc.
- Keeps Edit viewing and Log a viewing inside each viewing card.
- Moves Delete viewing into the Edit viewing form and asks for confirmation before deleting. The film itself is retained.
- Preserves the film journal, themes, search, settings, collections, backup/restore, and other existing app features.

To publish: upload the files in this ZIP to the repository root, replacing the existing files when prompted. Do not upload this README if you prefer a cleaner repo; it is only an instruction file. Keep the PNG icon files, manifest.json, sw.js, icon.svg and index.html together.
